Del 1: General information

When it comes to webdesign there is 3 programming languages you need to be familiar with, these are: HTML, CSS and JavaScript.


HTML (HyperText Markup Language) is used the make the structure and text of a website.

CSS (Cascading Style Sheets) is used to design the layout of a webpage.

JavaScript (Noen ganger forkortet til JS) is used to add interactivity and functionality to a website.

HTML consists of elements built from tags. A tag is a code that tells the browser what kind of content it is and how it should be displayed.

For example, to create a heading, you use h1 - h6 (different sizes).

When writing code in Visual Studio Code (a program used by many for coding), you can use shorthand versions like h1, p, a, img.

HTML code is quite easy to understand: p stands for paragraphs, and h1, h2... (up to h6) are different headings.

Part 3: CSS

CSS (Cascading Style Sheets) is used for styling and the layout of a website.

In CSS, you have the ability to change colors, fonts, margins, and padding, as well as the placement of elements on the page. This is done by using the HTML elements in the code. For example, you can style p by doing the following:

            p {
                color: red;
                font-size: 1.2em;
            }

This will make all paragraphs on the page red and slightly larger.

You can also style elements based on classes and IDs. For example, if you have a div with the class "kort", you can style it like this:

            .kort {
            background-color: #f0f0f0;
            border: 1px solid #ccc;
            border-radius: 8px;
            padding: 20px;
            margin: 20px;
            }

You can create a hover effect when the mouse pointer is over an element:

            .knapp:hover {
                transform: scale(1.08);
                transition: 0.7s;
                background-color: #5e81ac;
            }

This will give all elements with the class "kort" a light gray background, a gray border, rounded corners, and some padding and margin to make it more visually appealing.

CSS is a powerful tool for making your website more attractive and user-friendly, and it's important to learn it to create great websites!

Part 4: JavaScript

JavaScript (JS) is used to add interactivity and functionality to a website.

When writing JavaScript code, you can change the content of the page, react to user actions, and much more. Often you write "." to perform actions.

Here you see it says document.getElementById('element-id')

This method is used to find an HTML element based on its ID and manipulate it. The first part, "document," simply says it is the document being manipulated, and the second part is the code getElementById which is used to find an element in the code with an ID.

document.addEventListener("click", function() { ... }); is used to listen for click events on an HTML element.

If, else if, and else are used to create conditions in JavaScript. For and while are used to create loops.

querySelector and querySelectorAll are used to find elements in the HTML code based on CSS selectors.
